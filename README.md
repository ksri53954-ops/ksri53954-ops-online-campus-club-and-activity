# CampusConnect

A modern, responsive website for online campus clubs and activities.

## Features

- Discover popular student clubs
- Search clubs and events
- Save favorite clubs
- RSVP for upcoming events
- Club registration form
- Responsive mobile navigation
- Admin dashboard entry point

## Run locally

Open `index.html` directly in a browser, or serve the folder:

```bash
python3 -m http.server 8000
```

Then visit `http://localhost:8000`.

## GitHub Pages

In repository settings, enable Pages and deploy from the `main` branch using the `/ (root)` directory.
